# AgripulseAI-APP

### 🌾 Project Description
An AI-powered agricultural web application built using Google AI Studio. It is designed to process agricultural insights, analyze data, and help farmers optimize crop management using generative artificial intelligence.

### 🚀 Key Features
* **AI Chat Assistant:** Real-time conversational interface for crop diagnosis and farming recommendations.
* **Responsive Dashboard:** Built-in web UI for managing project assets seamlessly.
* **Automated Insights:** Instant analysis of agricultural queries using advanced AI models.

### 🛠️ Technologies Used
* **Frontend/Backend:** TypeScript, HTML, CSS (Vite project template)
* **AI Model Integration:** Google AI Studio (Gemini API)
* **Configuration Tools:** Node.js, npm, TailwindCSS

### 📦 Setup & Run Instructions
1. Open your terminal and clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the project folder:
   ```bash
   cd AgripulseAI-APP
   ```
3. Install the required project packages:
   ```bash
   npm install
   ```
4. Start the application locally:
   ```bash
   npm run dev
   ```
